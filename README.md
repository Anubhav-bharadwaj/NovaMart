# NovaMart 🛒

NovaMart is a full-stack MERN E-Commerce web application designed to provide a modern and scalable online shopping experience. The project focuses on implementing core e-commerce functionalities while maintaining a clean user interface and efficient backend architecture.

The application follows a client-server architecture where the frontend handles the user interface and user interactions, while the backend manages authentication, product APIs, database operations, and business logic. MongoDB is used as the primary database to store user and product information securely.

---

## 🚀 Project Overview

NovaMart was developed to simulate a real-world e-commerce platform with features commonly found in modern online marketplaces. The project demonstrates the integration of frontend technologies with backend services using REST APIs.

The frontend of the application is built using React and Vite, enabling fast rendering, component-based development, and smooth navigation. The backend is developed using Node.js and Express.js, which handle routing, middleware, and API communication efficiently.

The application architecture is designed to be modular, maintainable, and scalable for future enhancements such as payment gateways, admin dashboards, and order management systems.

## 🧠 System Architecture

NovaMart follows the MERN stack architecture:

- **MongoDB** is used as the database layer for storing products and user data.
- **Express.js** handles server-side routing and API management.
- **React.js** manages the client-side interface and dynamic rendering.
- **Node.js** provides the runtime environment for backend execution.

The frontend communicates with the backend through REST APIs, enabling seamless data exchange between the client and the server.

---

## 🌍 Deployment

The frontend application is deployed using Vercel, while the backend services are hosted separately to ensure better scalability and API handling.
