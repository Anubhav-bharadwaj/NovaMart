# NovaMart 🛒

A full-stack MERN E-Commerce web application built using React, Vite, Node.js, Express, and MongoDB.

## 🚀 Features

* User Authentication
* Product Listings
* Cart Functionality
* User Profiles
* Responsive UI
* REST API Backend

## 🛠 Tech Stack

* React + Vite
* Node.js + Express
* MongoDB
* JWT Authentication

## ⚙️ Run Locally

### Frontend

```bash id="rvf8sw"
cd frontend
npm install
npm run dev
```

### Backend

```bash id="gk1hxb"
cd backend
npm install
npm start
```

## 🔐 Environment Variables

Create a `.env` file inside `backend/`

```env id="c3j9e5"
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret
PORT=5000
```
